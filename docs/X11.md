# AnWind 内置 X11 桌面（v2.22.2）

AnWind 现在自带 X11 显示端：在终端里一条命令即可把图形化 Linux 桌面
（xfce4 / openbox 等）投射为**独立的全屏桌面**——不嵌入终端界面，画面
分辨率随设备屏幕自动调节。实现方法参考
[jiaxinchen-max/termux-app](https://github.com/jiaxinchen-max/termux-app)
的内置 X11 方案（基于 termux-x11 上游：lorie 合成器 + Xwayland 内嵌库），
并按 AnWind 的包名/前缀/桌面形态做了适配。

## 一、工作原理

```
AnWind 终端                        AnWind App 进程
────────────                       ─────────────────────────────
$ anwind-x11 :1
  └─ termux-x11 脚本
       CLASSPATH=宿主 APK
       app_process →
         CmdEntryPoint.main()
           native start():
             lorie + Xwayland
             （X server 运行在
              终端侧子进程）
           每秒广播 ACTION_START
           （binder 携带连接 fd）──→  AnWindApp 动态接收器
                                        └─ 拉起全屏 X11 桌面
                                           Activity（不进终端界面）
                                           └─ 从重播取 binder →
                                              getXConnection(fd) →
                                              LorieView 渲染
$ env DISPLAY=:1 startxfce4   ──→   X 屏幕尺寸 = 视图尺寸（自动调节）
```

- **X server 端**：`libXlorie.so`（四 ABI 预编译）随 APK 分发，由
  `app_process` 在终端侧子进程加载运行，X11 socket 落在 AnWind 自身
  的 `usr/tmp`，终端里的 X 程序直接 `DISPLAY=:1` 连接，无需任何代理。
- **显示端**：`com.termux.x11.MainActivity` 全屏 Activity，触摸/手写笔/
  外接键鼠/手柄映射/扩展按键条一应俱全（该模块原装能力）。
- **分辨率自适应**：`displayResolutionMode` 默认 `native`，X 屏幕尺寸
  实时跟随视图尺寸（旋转/全屏切换即时调整 X11 RANDR）。

## 二、与 X11 应用不冲突

| 维度 | AnWind 内置 | 官方 Termux:X11 应用 |
|------|------------|---------------------|
| 宿主包名 | com.anwind | com.termux |
| 广播目标 | `TERMUX_X11_OVERRIDE_PACKAGE=com.anwind` | com.termux |
| X11 socket | com.anwind 的 tmp | com.termux 的 tmp |
| 进程名 | `anwindx11` | `com.termux.x11` |
| 显示号 | 默认 `:1`（可用 `:0`/`:2`…） | 任意 |

两者可同时安装、同时运行，互不干扰。

## 三、使用

```sh
# 1. 安装桌面环境（首次）
pkg update && pkg install xfce4 dbus

# 2. 启动（自动弹出全屏 X11 桌面并拉起 xfce4）
anwind-x11

# 或指定显示号 / 只跑单个程序
anwind-x11 :1
anwind-x11 :1 xterm

# 3. 停止
anwind-x11-stop
```

也可以从 AnWind 桌面「开始菜单 → X11 桌面」直接打开显示端等待连接。

## 四、组件清单（本次交付）

| 位置 | 作用 |
|------|------|
| `termux-x11/` | X11 显示端 Gradle 模块（Java 源码 + 预编译 libXlorie.so ×4 ABI + 资源） |
| `termux-x11-stub/` | 框架隐藏 API 编译桩（compileOnly，运行期用真实框架） |
| `app/.../apps/x11/X11Desktop.kt` | 广播 → 拉起全屏 X11 桌面（去抖） |
| `app/.../apps/x11/X11App.kt` | 桌面/开始菜单「X11 桌面」入口 + 使用说明 |
| `assets/termux/scripts/termux-x11` | 终端侧客户端命令 |
| `assets/termux/scripts/anwind-x11` | 一键启动（服务 + 桌面会话） |
| `assets/termux/scripts/anwind-x11-stop` | 停止服务 |
| `assets/icons/x11.png` | 桌面入口图标 |
| `TermuxBootstrapInstaller`（rev 12） | 把上述脚本部署进 `$PREFIX/bin`，写 `etc/anwind-x11.env`（宿主 APK 路径 + nativeLibraryDir，App 启动时自愈刷新） |
| `CmdEntryPoint.java`（模块内补丁） | APK 以 `useLegacyPackaging=true` 打包时经 `ANWIND_X11_NATIVE_DIR` 从解压目录加载 libXlorie.so |

## 五、已知边界

- X11 显示端建议 Android 8.0+（模块 minSdk 26；低版本设备终端功能不受影响）。
- `libXlorie.so` 为参考仓库同款预编译产物；如需自行编译，参考
  jiaxinchen-max/termux-app 的 `termux-x11` 模块（git 子模块 + CMake）。
- Wine/游戏手柄映射等扩展功能沿用上游实现，未在 AnWind 界面深度集成。
